# Chat WA ke Investor (Paman)

## Versi Utama — siap kirim

```
Paman [nama], lagi santai? Mau cerita2 dikit nih.

Aku lagi bikin aplikasi Family Tree — buat nyimpen silsilah keluarga Indonesia sekaligus foto, cerita, sama acara keluarga dalam satu tempat. Jadi data keluarga yang biasanya cuma ada di chat, album lama, atau ingatan sesepuh, bisa rapi dan aman per keluarga.

Yang beda: hubungan kayak kakek, om, tante, sepupu, mertua dihitung otomatis sama sistem, dan udah dirancang buat nampung keluarga besar (100rb+ anggota). Aplikasinya udah jalan, siap aku demoin.

Rencananya modelnya freemium — mulai gratis, berbayar buat fitur arsip/ekspor yang lebih gede.

Kalau paman ada waktu, aku pengen minta pendapat + kalau kebetulan ada jalur ke investor atau keluarga yang mau bantu, boleh banget. Kapan enak ngobrol santai? Aku bisa mampir.
```

## Versi Singkat — buat buka obrolan dulu

```
Paman [nama], lagi santai? Aku lagi bikin aplikasi Family Tree buat nyimpen silsilah + foto + cerita keluarga Indonesia dalam satu tempat. Udah jalan nih, siap aku demoin. Kalau paman ada waktu, aku pengen minta pendapat dikit. Kapan enak ngobrol?
```

## Kalau Paman Tanya Detail

```
Jadi gini paman: data keluarga biasanya tersebar di chat, album fisik, dan ingatan orang tua. Kalau dibiarin, nama dan sejarahnya lama-lama hilang.

Family Tree ngumpulin itu semua jadi satu arsip per keluarga. Yang beda dari aplikasi lain: hubungan kayak kakek, om, tante, sepupu, mertua dihitung otomatis sama sistem, dan dirancang khusus buat istilah keluarga Indonesia.

Skalanya juga siap gede — bisa nampung 100rb+ anggota dalam satu keluarga.

Model bisnisnya freemium: gratis buat mulai, berbayar buat kapasitas media, ekspor, dan fitur heritage yang lebih lengkap.
```

## Kalau Paman Tanya Biaya

```
Buat demo sekarang biayanya Rp0, paman — infrastrukturnya udah aktif.

Nanti kalau udah mulai dipakai publik, perlu sekitar Rp1,6–2,5 juta per tahun buat tahap awal, terus Rp2–3 juta per tahun buat produksi. Kalau trafik dan fotonya banyak, baru sekitar Rp7 juta per tahun. Masih kecil sih.
```

## Tips karena keluarga

- Jangan langsung "jualan". Posisikan sebagai minta pendapat + timing, uang belakangan.
- Entry point paling gampang: minta dia jadi pengguna pertama keluarga kalian. Itu sekaligus demo + calon endorser.
- Jangan kirim deck panjang di WA. Kirim 1 pesan dulu, baru kirim deck kalau dia minat.
- Tutup dengan ajakan konkret: demo atau ngobrol santai, bukan langsung minta uang.
